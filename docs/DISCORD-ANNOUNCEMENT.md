**Introducing Hailstone Crest — standalone add-on preview**

Crest replaces world nameplates with configurable health, resource and cast bars. Start with the usable Default profile, choose a complete visual theme, or build your own setup.

- **14 profiles:** thin strips, inset frames, beveled metal, glass, runic designs and detached casts, plus Tank, Healer, Raid and Cast Focus setups.
- **223 settings:** per-unit appearances, combat styles, target decorations, stacking, health and aggro emphasis.
- **Health, mana/endurance and casts** from known game data, known self/target buff icons and a personal resource window.
- **Color swatches and a color wheel**, with RGB/hex controls and immediate changes.
- **Click plates to target:** enabled by default, with UI, cursor and drag protections.
- **Optional through-wall plates:** off by default.
- Character-specific settings, saved profiles, literal name rules and bounded profile import/export.
- Automatic startup through **Add-ons**, with an **Enabled** switch.
- Optional concealment awareness, pacify/mez indicators and shared markers when supported data is available.

Crest is its own add-on and works with your chosen interface. Its Lua renderer and themes ship in the add-on package. It requires the shared Hailstone UI API update that supplies generic nameplate canvases and managed Lua add-ons; that update is still under review. Once available, install Crest through **Add-ons** and open settings with **`/crest`**.

The current preview passes 131 Lua test cases and offline visual checks. Shared client integration and live multiplayer/controller acceptance are still being validated. This is a development preview, not a published release. Feedback and screenshots are welcome!
